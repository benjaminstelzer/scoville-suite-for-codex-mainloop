# Opus prüft, ob die Aufgaben Verständnis messen

## Decision

PLAN-0050 und seine konkreten Aufgaben mit vorab formulierten Kriterien vor dem suiteweiten Luna-Lauf von Opus 5.5/High abnehmen lassen. Die ursprüngliche Session bleibt erhalten.

## Problem

Ein erfolgreicher Test ist wertlos, wenn er Musterantworten nahelegt, notwendige Routen auslässt oder Ausführung statt Verständnis bewertet.

## Drivers

Realistische Rohfakten, unabhängige Kriterien, ausreichende Kontextversorgung, erhaltene Schutzregeln und Transfer über bekannte Beispiele hinaus.

## Considered alternatives

Eine reine Planlektüre ohne konkrete Aufgaben prüft die Messung nicht. Teilnehmer dürfen die Kriterien oder Reviewerbefunde nicht sehen.

## Consequences

Vor Luna-Dispatch werden verpflichtende Designfindings verarbeitet. Opus prüft read-only ohne Tests oder Skilländerungen; seine Abnahme belegt Testdesign, keine Modellleistung.

## Confirmation

Opus beurteilt Plan, Fragen, Kriterien und relevante Skillquellen auf Passung zum beauftragten Verständnisziel und benennt offene Abdeckung.

## Revisit when

Eine neue Aufgabenroute, ein veränderter Bewertungsmaßstab oder eine Antwort den Testaufbau infrage stellt.
