# W-007: Shared writing contract

`../shared/prompting/common.md` owns runtime writing rules. The authoring guide
adds Skill descriptions, English packaging, conditional references and helper
guidance without repeating general writing rules. General paragraphs in both
AGENTS files, Plan, Handoff and Workflow now refer to that contract. Native
records, retained history, Handoff source limits, UI approved copy and Workflow
control/result contracts keep their existing owners.

All eight Skills receive their own `references/writing.md` through shared:
manifest entries. Writing triggers are explicit. Ask's native and Claude
preparation paths include the same file before the literal question. Workflow
dispatch replaces its fixed general-writing paragraph with the file; the manager
helper names its own packaged path for reading after START. No new runtime
script is introduced; helper registry identities remain unchanged.
