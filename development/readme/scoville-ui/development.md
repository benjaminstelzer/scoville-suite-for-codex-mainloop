## How it was developed

Interface work, including WordPress admin pages, shaped UI. Repeated problems
with spacing, alignment and interaction showed why plausible code and a good
screenshot are not enough. Development put more emphasis on the existing
framework, rendered layout and actual behavior.

Ideas are tested in interfaces and compared with real project workflows.
Observed problems guide revisions to the guidance and checks, then the cycle
starts again. Usability still needs the people who will use the product.
