# Development

General interface guidance and WordPress rules initially lived apart. Bringing
them together helped the agent follow one design system while loading platform
rules only where they apply. Later checks exposed the gap between correct source
and a usable screen, including awkward text placement inside otherwise valid
components. Inspecting the rendered task flow matters more than counting rules.

The [source](../scoville-ui/) and tests live in the suite. Install the built package.
