# Development

Session transfers exposed how easily a summary loses a blocker or changes the
force of a decision. A compact continuation template made the needed facts
explicit, but a targeted test still promoted a preference to a requirement.
The lesson is to preserve what a statement means, not merely its topic. That
observed limit remains relevant when checking a generated handoff.

The [source](../scoville-handoff/) and tests live in the suite. Install the built package.
