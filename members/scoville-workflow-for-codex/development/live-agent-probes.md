# Native Mainloop acceptance probes

Run only an authorized test in a disposable Git fixture with matching packaged
Skills. No real projects, globals, installation, external product calls or
publication. Fixture commits must be explicitly authorized. Record actual child
handles, original units, pairs, complete results and decisive ordering compactly.
Unit tests, comprehension and observed native compliance are distinct evidence.

| Case | Required observation |
| --- | --- |
| Main implementation | Own active main pair matches. Main saves and validates start before editing exactly one original Step; no implementation child. Linked accepted Decisions are completely available before editing. |
| Fresh review and correction | Main establishes write/test/restore quiescence. A fresh read-only Reviewer checks the actual Step diff, effects and affected Acceptance. Defect correction stays on one original Step; the next Reviewer has a new handle and relevant open findings. |
| Unchanged Step | No file/config/behavior change and no open Step review: record completion without a Step review, invented pass or empty commit. |
| Commit boundary | Commit accepted versionable changes and Plan before advancing. Unexpected or foreign HEAD movement cannot hide effects behind an empty diff. Never absorb foreign work. |
| Closure | Fresh Reviewer checks all original Steps and full Acceptance from Work Item start commit plus required effect evidence. Missing proof blocks; defects select one affected Step. Each repeated closure is fresh. |
| Explorer | Questions and planning preparation go read-only to Explorer; main answers and writes the Plan. Reuse only for the same investigation or a follow-up on its findings, while idle with unchanged pair/rules. An independent request gets a fresh Explorer even in the same project/file. No repeated initialization on reuse. |
| Effects and proof | Preserve necessary ignored/nonrepeatable effects through existing evidence. Missing proof does not authorize repetition or invented success. No required per-Step report or source archive. |
| Stop/resume | Stop prevents new work; safely finish/stop started operations and establish child/process state. Explicit resume reconciles the same own work without premature commit or repeating accepted effects. |
| Compaction | Recover the same main thread's actual Plan, Git, processes, results and Decision bindings. No context measurement, threshold or automatic successor. Claim host-compaction coverage only if observed. |
| Failure/capacity | Unknown startup/result prevents duplicate dispatch. Confirm failure and termination before replacement. A timeout supplies no outcome; no automatic limit raise or capacity workaround. Close only if exposed; interrupt proves no freed slot. |
| Migration | Old version reaches reviewed quiet commit boundary; preserve old closure proof before reload. Explicit Setup cleanup is complete and atomic; commit tracked configuration before authorized continuation. Missing essential proof stops a mid-item switch. |

Use complete-file transport when needed. No receipt, startup handshake, context
telemetry or handoff-control tests. Scope, stopped work and unavailable native
features remain named limits, not simulated passes. The current authorized
Suite Plan owns required cases and comparison claims.
